# Sample handwriting fonts

The single sample response PDF uses the first locally bundled handwritten typeface:

- Caveat Regular — SIL Open Font License 1.1 (`Caveat-OFL.txt`)
- Kalam Regular — SIL Open Font License 1.1 (`Kalam-OFL.txt`)
- Patrick Hand Regular — SIL Open Font License 1.1 (`PatrickHand-OFL.txt`)

The fonts are embedded in generated sample PDFs. The sample uses Caveat for the student's handwritten name and nine ID digits. The other fonts remain available for future multi-student samples.
