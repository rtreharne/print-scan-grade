Before scanning

Create the answer key

Complete one printed sheet as the master answer key, then include it with the student sheets when you scan.

  1. Use student ID 000000000. This identifies the page as the answer key. Do not use a real student’s ID.
  2. Answer every question. Every question on the master sheet must have at least one filled bubble. An unanswered question cannot be marked or included in analysis.
  3. Use more than one bubble for a multiple answer question. Fill every correct option for that question on the master sheet. For example, fill A and C when both answers are correct.

You choose how multiple answer questions are scored during Grade. After scanning, select the answer key and set the marking rule: require all correct answers (AND) or accept any correct answer (OR). You can review this before exporting results.
